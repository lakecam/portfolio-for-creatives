Lumat

Spreadsheets to on-brand charts

A Mac app for anyone who makes charts from data. It checks a spreadsheet for errors, then turns it into on-brand charts that update when the file changes, with no account and no upload.

Role

Research and design (solo)

Timeline

21 Sep to 5 Nov 2026

Status

Concept, not yet tested

Platform

Mac app

Audience

Knowledge workers who visually articulate data, but do not have the technical ability or time to create custom branded visualizations

Problem

Chart tools get numbers wrong

  • Default charts look generic

    Excel and Sheets charts all look alike, and tools like Tableau are built for analysts.

  • Quick chart tools skip the checks

    Canva, Graphy, Piktochart, Datawrapper, and Flourish chart whatever they're given, errors and all.

  • Different units get added together

    1 tool added families, meals, volunteer hours, and cost per meal into a single Total bar.

Research

Testing 5 chart tools with 1 messy file

A fictional food bank report with 15 issues was tested across 5 tools. Issues counted if at least 3 tools flagged them.

Test results

Findings

  • Tools that warned about possible errors before completing a chart

    0

  • Tools the reasoning behind a particular chart selection

    0

  • Chart types on screen at once, with no guidance

    18+

  • Datawrapper, the only tool with a data check, turned 1,292 meals into

    1.292

Pivots

What changed after research

For chart makers, not nonprofits

Datawrapper and Flourish already serve nonprofits, so the focus moved to anyone making branded charts at work.

A Mac app, not a website

The spreadsheet never leaves the computer, and when next month's numbers arrive, the chart updates on its own.

Reflection

None of the 5 tools checked the data before charting, which is why Lumat does. With no users yet, these findings only cover the tools.

Test plan

3 sessions where people chart the test file with and without the data check, timing each and counting the errors caught.
